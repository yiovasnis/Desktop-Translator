# TranslatorApp

Aplicación de escritorio para detectar texto en pantalla en tiempo real y traducir automáticamente la palabra bajo el cursor.

## Tecnologías

- Python
- PySide6
- OpenCV
- MSS
- PaddleOCR (temporalmente)
- SQLite

## Project Architecture

- Layered Architecture  

## Core

- Contains the core logic and calculations required by the translator.

## GUI

- Contains the graphical user interface and user interaction components.

## services

- Contains the application services used by the translator.

## tests
- Contains tests used to validate the application's behavior.
